Laboratório de Segurança Web

O CCTE é um ambiente educacional desenvolvido para demonstrar vulnerabilidades em aplicações web de forma controlada. O laboratório permite realizar experimentos, observar técnicas de exploração, acompanhar mecanismos de detecção e defesa e analisar os registros produzidos durante as atividades.

Sobre o laboratório: cada área do CCTE contém vulnerabilidades implementadas intencionalmente para estudo, experimentação e observação em ambiente local e controlado.

As atividades permitem comparar o comportamento vulnerável da aplicação com os mecanismos de monitoramento, detecção, resposta defensiva e análise forense disponíveis no sistema.

  • Cadastro: SQL Injection
  • Login: SQL Injection e Brute Force
  • Perfil: IDOR (Insecure Direct Object Reference)
  • Comentários: XSS (Cross-Site Scripting)
  • Downloads: Path Traversal e File Disclosure

As técnicas apresentadas devem ser utilizadas exclusivamente no ambiente local e educacional disponibilizado pelo CCTE.
