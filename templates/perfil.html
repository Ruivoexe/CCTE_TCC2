Vulnerabilidade demonstrada

Esta página utiliza o parâmetro ?id= para selecionar diretamente o perfil apresentado ao usuário.

A implementação foi mantida propositalmente vulnerável para demonstrar IDOR (Insecure Direct Object Reference).

No ambiente vulnerável, a alteração manual do identificador pode permitir que um usuário tente consultar informações associadas a outro registro.

Comportamento educacional

No Modo Educacional, a aplicação permite que o identificador informado na URL seja utilizado diretamente, possibilitando a experimentação da vulnerabilidade de IDOR.

Na Defesa Ativa, o sistema compara o identificador solicitado com o usuário autenticado e pode negar requisições que caracterizem uma tentativa de acesso indevido.

Dessa forma, o mesmo procedimento pode ser utilizado para comparar exploração, detecção, registro e resposta defensiva.

PERFIL — VULNERABILIDADE DISPONÍVEL

IDOR

Insecure Direct Object Reference ocorre quando a aplicação permite acesso direto a um recurso por meio de um identificador sem verificar adequadamente se o usuário possui autorização para acessá-lo.

Implementação no CCTE

Nesta página, o parâmetro ?id= é utilizado para selecionar o registro apresentado.

No comportamento vulnerável, o identificador informado pode ser utilizado sem uma verificação adequada de propriedade do recurso.

Teste manual

  1. Faça login normalmente.
  2. Observe o identificador apresentado em seu perfil.
  3. Acrescente ou altere o parâmetro ?id= na URL.
  4. Teste outros identificadores existentes no laboratório.

Exemplos didáticos:

/perfil?id=1
/perfil?id=2
/perfil?id=3

Durante o exercício, observe os dados retornados, o Audit Log e o Security Log.

Comparação dos modos

Execute o procedimento primeiro no Modo Educacional e posteriormente com a Defesa Ativa.

No segundo caso, uma tentativa de acessar um identificador diferente daquele associado à sessão pode receber uma resposta defensiva.

As técnicas apresentadas devem ser utilizadas exclusivamente no ambiente local e educacional disponibilizado pelo CCTE.
