Categorias monitoradas

O mecanismo de monitoramento do CCTE classifica atualmente eventos relacionados às seguintes categorias:

  • SQL Injection
  • XSS (Cross-Site Scripting)
  • IDOR (Insecure Direct Object Reference)
  • Path Traversal
  • File Disclosure
  • Brute Force

Interpretação do Security Log

O Security Log representa a camada de detecção do CCTE.

Um registro neste arquivo indica que uma requisição apresentou características compatíveis com uma das categorias monitoradas pelo laboratório.

A existência do registro não significa, por si só, que uma mitigação foi aplicada.

No Modo Educacional, um ataque pode ser detectado e registrado enquanto a requisição continua até a implementação vulnerável.

Na Defesa Ativa, a mesma detecção pode resultar em uma resposta automática, como bloqueio, rejeição de conteúdo ou limitação temporária de requisições.

Essas ações defensivas são registradas separadamente no Audit Log.

Dados registrados

Cada evento pode conter informações como:

  • data e horário;
  • endereço IP;
  • método HTTP e endpoint;
  • categoria de ataque;
  • payload associado à requisição;
  • argumentos da URL;
  • identificador do usuário presente na sessão, quando disponível.

Segurança da interface forense

Os payloads registrados são apresentados como conteúdo textual nesta interface.

Dessa forma, códigos registrados durante testes de XSS são exibidos para análise sem serem interpretados como conteúdo executável pela página forense.

Isso permite examinar o conteúdo suspeito preservando a integridade da interface utilizada para análise.

Uso dos filtros

O filtro por tipo permite localizar uma categoria específica, como:

SQL INJECTION

XSS

IDOR

BRUTEFORCE

O filtro por IP permite investigar atividades originadas de determinado endereço.

O filtro por endpoint permite concentrar a análise em uma funcionalidade específica, como:

/login

/perfil

/comentarios

/download
